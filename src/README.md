# Frontend

O frontend atual está consolidado em `../index.html` para facilitar o primeiro teste. Na próxima etapa, separar o código em:

```text
src/
  components/    componentes visuais reutilizáveis
  pages/         visão geral, conversas, avisos e lembretes
  services/      cliente da API e autenticação
  state/         sessão, notificações e cache
  styles/        tokens da marca Tríade e estilos globais
```
